# 课程质量调研与重设计

## 基线与问题

基于 4ab5d4e 的 175 课全文结构扫描：1929 个步骤，每课只有一个 example；每课 explain 正文与要点总长均低于 250 字；没有 150 字以上的例文；542 道选择题没有解析。原先合计 3139 分钟的时长标注，不能支撑从零达到 N2 的完整能力承诺。

更严重的是结构问题：语言形式反复辨认、听写与组句经常复用同一句；缺少连贯文本、说话人意图、信息整合、汉字词汇语境、开放表达及明确评价标准。部分语法讲解过于绝对，例如把「は／が」简化为旧信息／新信息的固定规则。

## 实施计划

1. 保留现有 175 个路由与学习记录，将其组织为 35 个主题单元，每单元 5 课；课程编号表达学习顺序，不承诺固定天数达标。
2. 为每单元编写原创场景对话、连贯阅读、中文辅助、词汇读音表和理解题；初级逐步增量，中高级加入论点、限制条件与语域差别。
3. 为每课编写明确目标、扩展讲解、开放表达任务、示范及自查标准。共享单元材料用于连续五课的不同学习任务，不按重复出现次数虚报独立课文数量。
4. 接入现有课程播放器：讲解、例文、练习和小结各承担不同职责；保留原有答题与保存行为，新增理解题进入实际练习流程。
5. 补齐原选择题解析，修正已发现的语法绝对化和不自然表达；扩展教材与进阶标注、学习耗时同步。
6. 建立可执行的内容质量检查：单元覆盖、课时关联、原创材料重复、题目答案唯一性、解析、词汇读音、开放任务与参考答案；再做生产构建和浏览器回归。

## 验收边界

完成课程内容和软件验证不等于完成母语教师审校。浏览器朗读属于合成语音，不作为真人听力语料或口语评分。开放表达提供示范与自查，不以字符串匹配假装测出表达能力。

## 已实施的课程结构

| 阶段 | 单元 / 课数 | 主要交流任务 | 原创课文长度（日文字符，含标点） |
| --- | --- | --- | --- |
| 基础 / N5 参考 | 9 / 45 | 问候、介绍、购物、点餐、方向、时间与简单计划；音拍与假名贯穿 | 72–111 |
| 日常 / N4 参考 | 9 / 45 | 条件与安排、授受、请求与建议、事件顺序、旅行和服务通知 | 125–151 |
| 中级 / N3 参考 | 9 / 45 | 原因与立场、推测范围、制度说明、工作协调、新闻概括与道歉感谢 | 181–205 |
| 进阶 / N2 参考 | 8 / 40 | 观点对照、调查局限、公共政策、服务责任、趋势与争议、多来源综合转述 | 365–450 |

完整的 35 单元目录和 175 个逐课目标、作品要求见 [COURSE-OUTLINE.md](COURSE-OUTLINE.md)。由 `node scripts/export-course-outline.mjs` 从实际教材数据生成，避免文档与页面各写一套。

课程页现在按以下流程呈现：

1. **目标与讲解**：每课新增独立目标和展开说明，讲清连接形式、语境、语气及易错推论，再接原有基础讲解。
2. **例句与情境**：保留聚焦句型的短例句，补充四轮人物对话、连续课文、可展开的中文辅助、词汇和假名读音。支持逐句、全文和表达示范的设备朗读。
3. **理解与练习**：保留原题顺序，结尾新增一题阅读或听解。阅读提供原文；听解题只提供播放与问题，不在题面展示全文。这里练习的是已学单元的理解，不宣称是陌生语料考试。
4. **表达与复习**：每课给出独立写作或口头任务，先作答再展开示范。用信息完整、语言准确、语气与范围三个维度自查，并链接上一课和五课前的内容。

主题材料在连续五课复现，目标是从理解到形式分析再到表达。它们是 **35 篇独立课文，不是 175 篇独立课文**。每课建议时长为 25/30/35/40 分钟，可分次完成；不是完成等级学习的总学时估算。页面已去除“175 天”的固定周期表述。

## 学习记录与性能

- 保留全部路由和既有题目 ID；新增题目使用独立 ID。历史完成记录和首次成绩保留，页面明确提示可以重新练习扩展内容。
- 恢复答题与保存成绩时只统计当前课程仍存在的题目，旧版已移除题目不能抬高当前得分。
- 阅读题进入错题本时携带原文；听解题保留音频文本，避免复习时丢失答题依据。
- 全文教材由课程页面按课传入；首页和路径页的共享目录不携带课文、对话或步骤，只保留单元标题等摘要。
- 长课文换步后滚动到内容起点，避免读完长文后停在下一步底部；复习中的长题干采用适合段落阅读的字号与行距。
- 离线缓存版本升级为 v16，让已安装页面可更新到新教材。

## 自动检查与尚需外部验证的部分

新增 `validate-coursebook.mjs` 已纳入 `npm run validate:data`，验证 35 单元连续覆盖、175 课挂接、目标和任务不重复、材料长度、词汇读音、题目选项唯一性、答案与解析、阅读/听解显示边界、复习链接方向，以及目录不泄漏全文。它能阻止缺字段、错关联、混入其他文字或漏题等问题，**不能证明每句话的自然度，也不能代替真实学习者试用**。

最终验证结果（2026-09-08）：

- `npm run check`：内容校验、ESLint、**728 项单元测试**、生产构建全部通过；HTTP 检查覆盖 13 条页面路由、3 条 404 路由、385 个站点地图条目。
- `npm run e2e:browser:required`：通过。覆盖实际学习、错题、重练、保存失败、并发写入、移动端导航、布局以及 **32 个明暗主题页面/弹窗无障碍状态**。
- 新增课文界面验证：第 1、46、91、136、175 课在 390/1440 宽度下的 **10 个阅读视图**通过；听解答案保存、原文隐藏、表达示范展开行为通过。
- `npm run e2e:pwa:required`：通过，验证安装后的缓存与已访问页面离线使用。
- 阅读截图和结构数据：`output/playwright/course-20260908/coursebook/`；综合界面证据位于同级目录。日志保存在 `output/course-check.log`、`output/course-browser.log`、`output/course-pwa.log`。这些本地证据文件不纳入 Git。

验证中发现并修复了阅读题进入错题本时丢失原文、旧题答案可能抬高新成绩的兼容问题。旧目录标题的浏览器断言已随新文案更新；最终运行无失败或跳过项目。

仍需后续补强的教材能力：母语教师逐课审校、真人多说话人听力、系统汉字书写课程、学习者真实口头与书面作品反馈，以及官方公开样题对应的定时综合测验。本次完成的是覆盖现有 175 课的内容与教学流程重建，不宣称已达到商业教材的审校与音频制作水平。
