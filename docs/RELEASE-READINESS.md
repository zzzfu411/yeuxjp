# 发布、回滚与人工验收

适用范围：2026-09-05 修复后的本地优先日语学习应用。此文件是后续发布的操作清单，不表示已完成线上部署、日语专家审校或全设备认证。

## 1. 可重复发布

1. 使用 Node.js 24，在应用仓库执行 `npm ci`，安装内容严格取自锁文件。
2. 为目标站点设置 `NEXT_PUBLIC_SITE_URL`，使用最终 HTTP(S) 域名后构建。更换域名不会自动迁移用户的本地数据。
3. 修改课程、词库或显示索引后运行 `npm run generate:index`，提交生成的目录与条目索引；`validate:data` 会拒绝过期产物。
4. 执行 `npm audit --audit-level=moderate`。审查新公告及实际受影响条件；不把审计通过解释为不存在未知漏洞。
5. 本机运行 `npm run e2e:install`；Linux CI 运行 `npm run e2e:install:ci`，然后执行 `npm run check:release`。必须看到严格浏览器和 PWA 测试通过，不能接受 optional skip。
6. 保存日志、构建标识、锁文件及截图。确认元数据、设置/备份、错误恢复、首次加载、更新提示、离线回退和复习可用。
7. 在目标托管平台预览部署，确认 HTTPS、根路径资源、缓存响应头与配置域名正确，再进行正式发布。本次修复没有执行外部部署或修改 PR/分支保护。

CI 当前包含合并检查、按影响范围触发的严格浏览器/PWA 检查、依赖审计和手动完整发布检查。把对应状态设为远程分支保护规则需要仓库维护者在托管平台落实；本地工作树不能证明远程规则已经启用。

## 2. 数据兼容与回滚

- 新导出格式为 v4，导入兼容 v1/v2/v3。包含按日期聚合的学习日历；老版本已截断的历史日期无法恢复。
- 不建议直接降级到不理解新字段的旧客户端。回滚 UI/发布时优先使用保持 v4 读取、Web Locks 协议、课程 attempt 与辅助标记兼容性的修正版。
- 验证环境先导出备份，再演练导入、取消、重置和失败恢复。不要用生产用户的真实备份当自动测试夹具。
- 导入/重置会替换当前浏览器的数据，并使此前排队的保存失效。其他页面收到同步后应刷新；旧应用版本的标签页必须重新加载。
- 发布回滚不应执行 `localStorage.clear()`，也不应让 Service Worker 清除学习记录。PWA 缓存版本与学习数据版本分别维护。
- 浏览器清理站点数据、隐私窗口、存储空间不足、系统崩溃及换域名可能影响本地保存。Web Locks 解决协作标签页之间的并发读改写；它不将多键 localStorage 变成抗崩溃数据库事务。
- 不支持 Web Locks 或无法保存的环境会显示说明，并拒绝未经保护的学习写入。正式使用需支持该 API 的 HTTPS 浏览器；开发环境可用 localhost。未安装 Web Locks 的旧版客户端不在协调保证内。

## 3. 离线与语音边界

- PWA v11 安装时保存首页外壳、离线页、manifest 和安装图标；课程、词库、笔顺等按访问缓存。公共文件预缓存预算为 256 KiB，不包含动态首页 HTML 和后续页面资源。
- 导航缓存最多 40 项，运行时媒体缓存最多 64 项，存在淘汰。访问过不意味着永久可离线，也不代表首次安装已下载 175 课。
- 语音来自设备的浏览器 SpeechSynthesis。声音列表、日语音色、自动播放限制和离线朗读取决于系统，应用没有内置跨设备一致的语音引擎。
- 缓存更新应经过等待状态和用户刷新动作；严格测试检查安装、缓存分区、资源预热、离线导航、查询深链、真实笔顺资源、更新控制与数据保留。

## 4. 内容质量状态

当前课程为 175 天 N5→N2 路径，词汇 1,066 条、语法 187 条、语义/语用各 100 条。自动校验确认 ID、引用、答案、选项结构、课程覆盖关系和部分文本格式。**未逐句完成日语专家审校，等级标签不构成完整 JLPT 覆盖或能力保证。**

建议按批记录审校责任人与结论，至少包含：

| 项目 | 检查内容 | 本轮状态 |
|---|---|---|
| 日语准确性 | 词义、假名、汉字、自然语序、活用、助词、可接受答案 | 结构与抽样检查；完整人工审校待做 |
| 教学递进 | 前置知识、复现间隔、负荷、词汇/语法与等级适配 | 引用与路径自动校验；教学专家验收待做 |
| 语义/语用 | 礼貌程度、场景边界、文化概括、易误导解释 | 搜索和阅读可用；专家逐项核对待做 |
| 测量效度 | 随机选项、提示辅助、独立输出与自评区分 | 代码及行为修复已覆盖；长期效果未验证 |
| 来源与许可 | 内容来源记录、例句授权、第三方资源许可证 | 现有 AnimCJK 许可证保留；内容来源追踪持续维护 |

对发现的争议条目，在更正记录中保存条目 ID、原文、改文、原因、审校人和日期；不通过重命名 ID 解决文案问题，避免丢失已有学习关联。

## 5. 真机和人工验收表

| 环境/场景 | 操作及通过条件 | 本轮验证范围 |
|---|---|---|
| Chromium 320/390/1440 | 页面无横向溢出、菜单/分页/深链可用、课程正文与首词可见 | 本机自动浏览器及截图 |
| 亮/暗主题 | 小字、选择态、错误态清楚，焦点可见 | 28 个页面/弹窗自动检查及视觉抽查 |
| 键盘 | Tab/Shift+Tab、Escape、焦点回到触发器、背景不可聚焦 | 浏览器流程覆盖 |
| 日语输入法 | Enter 先确认候选，再提交答案 | Chromium 组合事件模拟；真实 IME 待验 |
| VoiceOver / NVDA | 标题、表单标签、答案反馈、弹窗名称与阅读顺序 | 未运行真实读屏；axe 的 incomplete 项保留作人工清单 |
| iOS Safari / Android | 安装、更新、返回前台、离线、键盘遮挡、缩放、系统分享备份 | 未在真机执行 |
| 日语 TTS | 声音选择、停止、连续朗读、离线表现、发音质量 | API 路径覆盖；实际音质未验 |
| 错误恢复 | 重试、重新加载、回首页、诊断复制且无学习内容 | 恢复组件安全渲染测试；真实服务端故障场景待验 |

自动无障碍检查不能覆盖背景纹理上的所有对比度、读屏理解、交互舒适性和认知负担。保留自动检查中 `incomplete` 的元素清单，不把 0 violations 写成 WCAG 认证。
