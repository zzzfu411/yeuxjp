## 设计约束

- 暖纸白 `#fffdf9`：页面与封面；墨蓝黑 `#26263b`：正文；莓红 `#ac3758`：白天主操作。
- 夜墨灰 `#191b20`：暗色底；夜间纸面 `#272a30`：层级；浅金 `#e4c180`：暗色强调。
- UI/中文沿用 Segoe UI / Microsoft YaHei / PingFang SC，日文沿用 Yu Gothic / Hiragino / Noto Sans JP。说明 16 px、正文 17 px，标题根据层级响应式变化。Logo 保留已有书法图，不用字体模拟。
- 原图作为唯一大幅主视觉；角色配图作为陪伴性小画面；粗描边集中在主操作与关键画面，说明和辅助资料使用细分隔。
- 每页先回答“现在做什么”，再提供“为什么/全部内容/统计”。展开区域不能删除功能，已开始任务和错误不能被隐藏。

```text

回廊 + 开始课程                   回廊 + 开始课程
进度大卡 / 两个练习大卡             今日安排摘要 + 开始 / 展开

完整目标任务 + 写作编辑器            三个目标任务 → 独立练习页

此前路径                         调整后路径
长介绍 → 推荐 → 45课 → 统计         简介 + 起点 → 推荐 → 当前单元5课
目标编辑器 → 所有专项               其他单元/阶段可展开 → 统计/专项详情
```

审视取舍：不压小文字、不裁原图、不用大面积装饰弥补内容；折叠的收益必须通过首次使用/展开/返回/续学共同验收。
