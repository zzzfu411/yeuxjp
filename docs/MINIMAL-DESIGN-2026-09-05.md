# 简约日系前端设计

用户要求：前端要有简约的美；保留此前指定的加藤惠。调整信息结构与全站视觉，保持学习算法、课程内容和已有数据。

## 设计方案

- 色彩：暖白 #faf9f6、纯白 #ffffff、墨灰 #30332f、灰褐 #696a64、浅灰 #deded8、樱粉 #a94c60。樱粉只强调主要操作和选中状态，答题对错保留语义色。深色模式使用炭灰与浅色文字。
- 字体：首页用明朝/宋体系统字体，界面用清晰的无衬线字体。正文 14–16 px，内页标题 28–36 px，首页标题 56–72 px。
- 布局：首页左侧品牌、短文案和唯一学习主操作；右侧是有明确边界的加藤惠插画。下方直接展示进度和两个练习入口，不套大卡片。
- 导航：四个桌面常用入口加完整菜单。手机使用带文字的菜单，全部功能保持可达。
- 设置：简短摘要加按钮打开弹窗。首次访问沿用现有默认学习逻辑，关闭弹窗恢复焦点，保存失败保留选择以便重试。
- 原则：以留白和对齐区分内容；每种数据只出现一次；边框用于必要交互；避免重复标签、渐变底色和彩色装饰。

```text
優しい                  今日  课程  五十音  复习     听力  主题  菜单

     優しい日本語                 ┌───────────────┐
     每天一小课，和日语慢慢靠近。   │               │
                                  │  加藤惠插画   │
     今日课程                     │               │
     下一课标题                   └───────────────┘
     [开始 / 继续学习]              君と、ことばを重ねて。

     学习进度                     今日复习   到期数量
     今日练习细线进度             薄弱项     推荐内容
     课程 / 入门词 / 连续天数
     设置摘要 · 学习设置

     Yasashi Japanese                        数据备份与设置
```

手机按标题、紧凑插画、课程入口排列，阅读顺序与视觉顺序一致，常见手机首屏可见主操作。

## 自我审查

1. 只删装饰不能解决杂乱，因此合并三处重复课程入口；完整课程放在学习路径，首页不再展开 45 节课。
2. 缩小人物可能损失日漫氛围，因此保留可辨识的头部、服装与昼夜插画，不用浮层遮挡人物。
3. 极简可能让入口难找，因此常用功能直达、菜单带文字、学习设置与真实进度保持可见。
4. 全站去除渐变背景、标题彩色下划线、装饰菱形、多色卡片顶线和非必要阴影；保留焦点、悬停、弹窗层级与 reduced-motion。

## 验收

### 已实现

- 合并首页三个学习入口，保留一个主操作。取消默认展开的课程目录，完整课程仍在学习路径中。
- 学习设置改为显式打开的弹窗；初次访问直接使用现有默认学习逻辑。测试覆盖创建、修改、取消、写入失败重试、键盘关闭与焦点恢复。
- 导航保留四个桌面常用入口，菜单提供全部十个页面。首页进度、复习和薄弱项直接展示，不套外层卡片。
- 全站统一暖白/炭灰背景，去除彩色底纹、标题装饰线与非必要阴影。术语链接使用不透明的强调色，保证可读性。
- 五十音缩短介绍，读音提示按需展开，装饰横幅换成简短标题；词库减少重复标签、嵌套边框和顶部空间；复习页收起听力设置；课程侧栏标题缩小。
- 首页插画沿用加藤惠昼夜资产，没有新增外部请求或依赖。PWA 缓存版本更新为 v14，并同步浏览器主题色和离线页背景。

### 实看结果

1440 px 桌面采用左右两栏；390 px 手机首页全文约 1243 px，开始学习按钮在首屏内。词库第一张卡片从约 629 px 开始，第一个单词在约 777 px 处完整显示。320、390、768、1440 px 首页均无横向溢出，明暗插画正确切换。

验证涵盖 724 项单元测试、数据校验、ESLint、生产构建、13 个路由及 3 个 404 页面、385 条 sitemap 地址。无障碍检查扩展到 32 个明暗页面及弹窗状态；自动检查不代替辅助技术实测。新弹窗的颜色检查等待入场动画结束，避免测量淡入过程中的中间透明度。

最终生产版本验证全部通过：

- `npm run check`：数据、lint、724 项测试、构建与 HTTP 检查通过。日志：`output/minimal-check.log`。
- `npm run e2e:browser:required`：并发学习写入、完整学习/复习流程、保存失败重试、移动端、键盘操作和 32 个无障碍状态通过。日志：`output/minimal-browser.log`。
- `npm run e2e:pwa:required`：真实离线页面、课程、插画、缓存和升级流程通过。日志：`output/minimal-pwa.log`。
- 生产版首页检查：8 种尺寸/主题组合、4 次首页 axe 扫描均通过，无页面异常。另有 24 张内页截图和 4 张弹窗截图供实看。
