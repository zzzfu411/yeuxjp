# 测评版本与独立输出证据

## 题目与课程版本

`lesson-content-fingerprint.ts` 选择稳定的内容字段生成版本，不将客户端临时 attemptId 纳入。题干、标题、音频文本、答案、允许答案、选项、提示、词块或解析变动均改变版本。它是内容身份指纹，不用于安全校验。

`legacy-question-versions.ts` 是引入版本机制时冻结的兼容基线，共 1,535 项。已知错误题不在其中；不允许在未来编辑课程后重新生成该文件，否则会把改题后的旧记录错误地重新认定为有效。旧记录没有版本时，仅允许匹配这份基线的题目恢复。

新题记录保留 questionVersion；恢复 UI、读取历史练习、阻止重复提交以及结课算分均检查当前版本。发生变化时重新作答，旧 correct 值不会直接恢复。替换旧答案会以 `stepId@version` 存入 supersededAnswers，保留首次完成和首次成绩。新一轮补学成绩写入 attemptScore。

完成课程后记录 completedContentVersion 和 completedStepVersions。小结列出变动或尚无学习版本证据的内容；“仅补学这些内容”建立独立轮次，保留原答题状态，导航只访问差异与小结。教材阅读材料的变动也会进入差异。

## 输出指标

responseFormat 区分 choice、assembly、input。动词变形选择题按识别记录；组句为受限回忆。错题回放按实际展示方式重新判断，原先输入题如果此次显示为选择题，也不能算独立输入。

outputEvidence 只接受 production 模式下、未辅助的 input 记录。它从零建立新的可信样本，不把旧混合 production 的 100 分复制过来。旧分数与次数仍存储，但不再支撑当前独立输出指标；页面明确展示样本量、知识点数以及不代表口语/开放表达能力的边界。

## 验证

- 同 ID 改题失效、展示临时状态不影响版本、兼容基线、过期日志过滤。
- 只补修订内容、刷新恢复、保留首次 75 分与完成日期、新轮次得到独立成绩、旧答案归档。
- 备份规范化往返后保留版本、归档和输出证据。
- 连答六次变形选择题，独立输入仍未测；旧 production=100 保留但不当成可信输出；新输入从 18 分证据起算；未辅助的错误输入显示已测 0 分，而非“未测”。
- 当前全量 743 项单元测试通过，开发预览三项专项浏览器验证通过。完整生产发布验证在整体整改最后执行。

## 旧错题与受影响的历史能力分数

错题兼容采用只读筛选：题目版本不适用、同音假名冲突、相同中文释义互斥选项的旧题退出正常复习，显示停用原因与返回练习入口。原始快照不删除；重新答错的新版覆盖同一错题 ID 时，旧快照以 history 后缀归档。备份规范化保留版本与归档标记。到期数、今日队列与重新加入复习都只读取有效错题集合。

课程题通过精简的内容身份索引与冻结旧版本基线核对；语法专项比较稳定内容版本，选项展示顺序不参与版本。每次生成索引及 validate:data 都检查索引是否与教材同步。当前未变化的旧语法题可以继续复习，但展示选项按轮次打乱；同一轮反馈不会改变选项位置。

历史聚合没有逐题来源，不能可靠拆分某个分数里哪些部分来自有问题的旧题。因此对明确受影响的“知识点＋能力模式”保留原始分数，但暂不作为当前能力依据。范围为语法专项固定位置涉及的识别能力、41 道标题泄漏题涉及的听力能力、同释义词回忆、六个同音假名听力及第 135 课变体涉及的组句回忆。其他模式继续有效，不清库、不全体置零。

新答题写入 assessmentRevision；未辅助的实际测验建立独立 assessmentEvidence。旧日志重放、旧版本标记、词卡自评不会把受影响旧分数重新变为可信证据。首次新答对累积 18 分，答错产生已测 0 分；历史累计分数和次数仍保留。路径页说明需要重新验证的知识点数量。

边界：本次聚合分数隔离针对明确列出的审计风险，不能恢复旧日志中已丢失的逐题来源。未来发现新的教学错误时，仍需扩展受影响范围或升级测评修订规则；不能把题目快照自动失效描述为所有聚合证据自动重建。

新增验证：四项旧错题反例、三项历史能力证据反例；verify-retired-mistakes.mjs 验证到期过滤及原始快照保留，verify-assessment-history.mjs 验证从旧 100 分独立建立新 18 分并刷新恢复。

后续复查新增范围：旧混合错题曾在答前显示解析、纯听音目标假名，以及非听力题填好答案的音频。现已将解析移至提交后，听力只显示“听音作答”，非听力题不提供可能泄漏答案的音频。具有解析的课程题、平假名听力与助词专项所涉及的历史聚合模式加入受影响范围；仍按知识点和模式隔离，不删除历史值。

## 正确语法与句子的间隔复习

knowledge reviews 与错题本分开存储。独立答对后保存原题快照、词块、目标语境、允许答案及版本，首次安排 10 分钟后复习；再次在课程答对相同题目不会重置到期。到期后进入首页计数及今日混合队列，提交成绩与 SRS 更新在同一存储事务内。选择题继续选择，组句继续操作词块，输入题继续输入，不更改能力类型冒充开放表达。

快照失效时保留原始数据并暂停出题；新题使用包含源版本和呈现内容的身份。早期快照 ID 仍可恢复，不相容语境可保留旧卡后建立新卡。备份 v5 引入快照及复习状态，当前 v7 同时包含作品与每日安排，兼容 v1–v6 导入。旧正确答案没有可靠快照时不凭聚合分数伪造历史入队，可在课程补练后建立新的复习记录。
## 课程巩固与集合补测补充

课程完成记录与当前逐题测评分别使用。`lesson-assessment-index.ts` 由课程生成，列出当前题目 ID/版本；课程测评仅使用显式匹配版本的逐题记录，辅助正确不计独立正确。所有题均有有效作答且独立正确率至少 80% 时标记“本课测评达标”。这是产品内练习门槛，不是长期记忆、开放表达或考试级别认证。旧汇总分数与首次日期不被重写，无版本旧答案仍能作为历史记录查看，但当前状态要求补测。

针对性补练沿用差集轮次的导航与持久化，只清除待补测/错误/辅助答案；这些旧答案归档到 supersededAnswers，有效独立正确答案保留。补练得分计入新轮成绩；首页与路径读取相同的当前证据，且不取消已解锁的下一课。

本课假名补测分别统计 recognition/listening 的实际 assessmentEvidence，不把手动标记、课程完成或无法区分来源的旧汇总当成有效测试。平/片假名 ID 独立，第一次作答的测评与 SRS 安排保持原子写入。

## 开放作品与阶段迁移材料

`written-work-model.ts` 将任务、目标量表和作品一起保存。任务内容版本变化时建立新记录，旧任务、草稿和完成状态可查；阶段材料正文也参与版本。本人完成自查必须有非空笔记及所有量表勾选，但该状态不等于作品正确或能力认证，未产生任何自动 PracticeResult。

编辑即时排入学习写入锁，作品令牌只比对本作品，允许不同作品独立保存；冲突不覆盖已有作品。本页尚未保存文字保留，失败或待保存时触发离页保护。编辑时记录的数据 epoch 阻止重置后排队写入复活作品。备份 v6 开始携带所有作品版本，当前 v7 兼容 v1–v6。

## 每日安排与学习日期

备份 v7 增加 DAILY_STUDY_PLANS，按本地日期保存预算、任务说明、固定入口和阅读本人确认时间。重新安排追加记录，旧安排不被覆盖；查看首页本身不会创建安排。表达任务关联作品 ID 和版本，只有对应版本在当天完成全部自查才满足任务。

日历的 reviewCount 仅来自真实评分的复习/补练，不包括课程作答或词卡自评；旧记录没有来源时不推测复习次数。selfReportedStudy 表示当天曾本人确认阅读片段或完成表达自查，可用于连续学习日期，但不增加任何答题/正确次数。后来修改作品或撤销任务勾选会撤销当前任务完成，已发生的自报活动日期保留。任务/作品和日历一同提交或回滚。

预算是可分次执行的估计，不是停留时长或能力证据。带预算入口的复习每题本轮只作答一次，答错仍按 SRS 留待近期复习。

## 复习变式与小结

`knowledge-review-variants.ts` 由教材及语法专项生成，随 `generate:index` 更新、由 `validate:data` 校验。语法按知识点轮换既有例句；读听理解只在材料完全一致、测评模式一致的组内换题，不把文字理解记录为听力。每个替代题保留自身的题目版本与知识点 ID，其实际作答记录独立于课程完成。

首次或近期答错使用原题；已答对且到期、未逾期七天以上时尝试轮换。组句在两次正确复习后可交替使用词块和不提供词块的原句回忆；回忆使用现有审定答案，记录 recall + input，不代表独立自由表达。未配置变式的其他题型明确回顾原题。

同一轮队列保存进入时的 SRS 快照，题目在答后反馈期间不会受刚更新的计数影响。评分仍安排原知识卡的下次复习，原题快照不被变式覆盖；旧快照是否可用继续由源内容版本判断。题目轮换本身不需要新增备份字段。

课后小结逐项区分当前版本作答与复习状态。正确题有未来安排、错误题可以到期、历史完成仍可能未测；这些事实分别展示。声明但未单测的知识点标为仅接触，并提供资料/补练入口。读取失败时显示错误，不使用空集合伪造“未测”状态。

N5–N2 四份阶段作品使用独立原创材料，与课程中的五课共用阅读分开。页面分别呈现课程知识证据与作品自查，说明重复阅读后的材料已不是未见材料。独立阶段诊断由 D08 另行实现，不用自查作品替代考试或诊断成绩。
