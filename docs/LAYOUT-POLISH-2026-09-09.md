# 首页布局收尾

目标是协调、简约、大方，保留已确认的角色与漫画语言。将插画和主要学习按钮作为重点，其余界面减少重复装饰。

沿用纸白 #FFFDF9、墨线 #08090B、炭灰 #191B20、纸金 #E4C180、樱色 #AC3758。中日文无衬线字体及 17px 正文不变；标题保持大字。沿用左文右图，下面两列等宽，手机单列。

```text
[ 大标题与说明   | 加藤惠 ]
[ 今日课程/开始  | 插画   ]
[ 学习进度/爱蜜莉雅 ] [ 复习/红莉栖 ]
[ 进度数字         ] [ 薄弱项练习  ]
```

审视现有页面后，重复的英文品牌、小框标签、TODAY 标记和右下角装饰句占用了注意力，因此移除这些元素。保留对话气泡、角色小漫画框和黑色按钮，避免把项目改成没有日漫特色的普通仪表盘。统一下方卡片的列宽、留白与墨影，配图保持清晰且不遮挡文字。

实施完成：桌面主画面最小高度由 680px 调整为 620px；下方等宽两列，统一 24px 内边距和更轻的 2px 墨影；小漫画框倾角收至 ±1°，平板与手机采用 108px 配图，桌面 144px。清理移除元素对应的无用 CSS。

验证：构建、ESLint、4 项首页契约测试通过；320/390/768/1024/1440px 的明暗主题共 10 个视图无横向溢出，三张配图加载正常，课程入口、复习入口和设置弹窗通过操作检查。32 个页面与弹窗状态的自动可访问性检查通过。已查看桌面、平板、手机截图；生产预览 3217 已更新。证据保存在 `output/playwright/layout-polish-20260909/`。
